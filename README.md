# 嵌入式数据库与存储引擎

## 项目描述

嵌入式数据库与存储引擎的bug修复项目。核心模块 `storage/embedded_db.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- B树索引完全没做每次查询全表扫描
- 事务没有原子性写到一半崩溃数据丢失
- WAL日志完全没做崩溃后无法恢复
- 查询优化完全没做总是用最慢执行计划
- 并发控制完全没做同时写覆盖先写的
